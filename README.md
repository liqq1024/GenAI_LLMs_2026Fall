# GenAI_LLMs_2026Fall
This repository is the central course workspace for the Generative AI and Large Language Models including lecture resources, live coding, and the semester-long project. It is updated weekly as new course material becomes available.
## Before every lecture

Pull the newest materials before class:

```bash
git pull origin main
```

If you have made changes of your own, save them first with a commit or use a separate copy of the repository for personal work. In GitHub Desktop, select **Fetch origin**, then **Pull origin** when updates are available.

## Repository contents

| Folder | Contents |
| --- | --- |
| `lecture-materials/` | Weekly slide decks in PDF format for offline review and reference. |
| `colab-notebooks/` | Interactive Jupyter/Colab notebooks for live demonstrations and coding exercises. |
| `code-samples/` | Reusable boilerplate for Hugging Face models and API implementations. |
| `assignment-templates/` | Project starter materials, required deliverables, and submission guidance. |

## Getting started

1. Install [Git](https://git-scm.com/downloads), or use GitHub Desktop.
2. Clone this repository:

   ```bash
   git clone <repository-url>
   cd <repository-folder>
   ```

3. Open notebooks in [Google Colab](https://colab.research.google.com/) or Jupyter.
4. Review the relevant weekly folder before class and pull updates before each lecture.

## Course resource conventions

- Weekly resources use the format `week-XX-topic-name`.
- PDFs are intended for reference; the corresponding notebook contains runnable examples when applicable.
- Never commit API keys, tokens, datasets containing sensitive information, or student submissions to a shared course repository.
